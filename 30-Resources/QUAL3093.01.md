## Summary

Form QUAL3093.01 provides a structured log of construction contract submittals, recording submittal identifiers, descriptions, types, receipt and return dates, assigned reviewers, review duration and disposition actions for each submission.

## Details

### Header

#### Project Identification

- Project name
- Project number
- Client name
- General contractor or construction manager
- Designer name
- Review type (traditional or nontraditional)

#### Log Settings

1. Date the submittal log is initiated
2. Identification of responsible parties for submittal processing

### Submittal Log Table

#### Columns

- Submittal ID and description
- Type of submittal (actionable or informational)
- Date received
- Reviewers assigned
- Days in review
- Actions taken
- Return date
- Copies distributed to parties

#### Entry Process

1. Enter a row for each submittal received
2. Complete all columns to track review and disposition details

### Action Definitions

#### Standard Actions

- NO EXCEPTIONS TAKEN: fabrication may proceed based on conformance to design intent
- FURNISH AS CORRECTED: proceed after making the noted corrections
- REVISE AND RESUBMIT: no fabrication may proceed until requested revisions are made
- SUBMIT SPECIFIED ITEM: submit specified items to the reviewer for approval
- REJECTED - SEE REMARKS: no fabrication or construction may occur until remarks are addressed
- FOR INFORMATION ONLY: record purposes only, no further action specified

#### Usage Notes

1. Mark the appropriate action code in the actions column for each submittal
2. Refer to nontraditional review modifications if applicable

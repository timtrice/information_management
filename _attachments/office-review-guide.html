📝 WORD: Track Changes for Reports & Specifications
🎨 DOCUMENT ORIGINATOR
  1. Prepare document
    • Review tab → Track Changes ON
    • Set user name (File → Options)
    • Lock tracking if needed (with password)
  2. Save to SharePoint
    • File → Save As → SharePoint location
    • Or upload to Teams channel
  3. Share for review
    • Click Share button
    • Set permissions (edit/comment/view)
    • Add message for reviewers
  4. Monitor changes
    • See who's currently editing (presence)
    • View changes in real-time
    • Respond to comments
  5. Finalize document
    • Review → Accept/Reject changes
    • Delete resolved comments
    • Compare versions if needed
💡 PRO TIP: Use "Simple Markup" view during review to see clean document with change indicators in margin. Switch to "All Markup" to see details.
✍️ REVIEWERS
  1. Open shared link
    • Opens in Word desktop or browser
    • Your name appears on edits
  2. Review tools available:
    • Track Changes for edits
    • Comments for questions/suggestions
    • @mentions to notify specific people
    • Reply to existing comments
    • Suggest formatting changes
  3. See others working
    • Colored flags show who's where
    • Changes appear as they type
    • No save conflicts
  4. Review complete
    • All changes auto-saved
    • Can leave final comment
    • Close and changes persist
⚠️ IMPORTANT: Track Changes must be ON before editing. Check the Review tab - if it's OFF, your changes won't be tracked for QA!
📊 EXCEL: Comments & Change Tracking for Calculations
💬 Comments & Notes
Two systems: Comments (threaded conversations with replies) and Notes (simple annotations). Comments are perfect for review discussions. Right-click any cell → New Comment.
🔒 Protection with Exceptions
Protect sheets but allow specific ranges for input. Review tab → Protect Sheet → Select what reviewers can change. Perfect for calculation templates.
📝 Track Changes (Legacy)
Review tab → Track Changes → Highlight Changes. Shows who changed what cell and when. Note: Being phased out in favor of version history.
🔄 Version History
File → Info → Version History. See all previous versions, who made changes, and restore if needed. More reliable than Track Changes.
👁️ Show Changes
New feature in 365: See changes highlighted in real-time as others edit. Green = additions, Red = deletions. Temporary visual during co-authoring.
✅ Data Validation Comments
Add input messages and error alerts to cells. Data tab → Data Validation → Input Message. Guides reviewers on acceptable values.
💡 EXCEL BEST PRACTICE: Create a "Review Log" worksheet in your file. Include columns for: Reviewer, Date, Cell Reference, Issue, Response, Status. This becomes your QA documentation.
⚖️ Office Native vs. PDF-Based Review
Aspect Office Native Review PDF Review (Adobe/Bluebeam)
File Format Stay in Word/Excel - no conversion Must export to PDF first
Real-time Collaboration ✓ Multiple users simultaneously ~ Sequential or managed sessions
Change Tracking ✓ Automatic with user names ✗ Comments only
Version Control ✓ Automatic in SharePoint ~ Manual versioning
Formula Checking ✓ Can audit Excel formulas ✗ Formulas not visible
CAD Drawings ✗ Not suitable ✓ Designed for drawings
Final Deliverable Export to PDF after review Already in PDF format
QA Documentation ✓ Changes tracked automatically ~ Export comment summary
✅ Meeting QUAL3130 Requirements with Office
📝 Automatic Audit Trail
Every change shows: who, what, when. Reviewing Pane in Word shows complete history. Excel comments are timestamped. Meets traceability requirements.
🔒 Authentication
Users authenticated through Microsoft 365 accounts. Changes tied to corporate identity. Can add digital signatures through Insert → Signature Line.
📁 Folder Compliance
Files stay in your Admin folders during review. No need to move for review process. Final PDF goes to 17-Deliverables after changes accepted.
📊 Review Summary
Word: Print markup summary or save as PDF with comments. Excel: Export comments or create review log. This replaces separate QA forms.
⚡ Quick Reference Guide
🚀 Starting Co-authoring
Word/Excel:
1. Save to SharePoint/OneDrive
2. Click Share button (top right)
3. Enter email addresses
4. Choose "Can edit"
5. Add your message
6. Send

Everyone can now edit simultaneously!
⌨️ Essential Shortcuts
Word:
Ctrl+Shift+E - Track Changes
Ctrl+Alt+M - New Comment
F5 - Go to specific change

Excel:
Shift+F2 - Add Comment
Ctrl+Shift+L - Filter
Alt+R+G - Protect Sheet
👥 @Mentions
Type @ in a comment followed by someone's name. They get an email notification with a link directly to that comment. Great for getting specific input.

Works in: Word, Excel, PowerPoint
📊 Version Comparison
Word:
Review → Compare → Two versions

Excel:
File → Info → Version History
Click any version to open

SharePoint:
Right-click file → Version History
🔒 Locking Tracking
Force Track Changes:
Word: Review → Track Changes → Lock Tracking (set password)

Now NO ONE can turn off tracking without the password. Ensures QA compliance.
✅ Creating Final Version
Word:
1. Accept all changes
2. Delete all comments
3. File → Info → Check for Issues
4. Save as PDF for deliverable

Keep the marked-up version for QA records!

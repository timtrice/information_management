⚠️ CRITICAL RULE: Always upload BOTH the native CAD file (.dwg) AND the PDF export. The CAD file is for record-keeping, the PDF is for review and approval.
👥 Step-by-Step Instructions
🎨 FOR DESIGNERS/DRAFTERS
  1. Finish your drawing in CAD software
  2. Plot to PDF:
    • Use "DWG to PDF.pc3" plotter
    • Select "Full Size" (not "Fit to Page")
    • Include layers & lineweights
  3. Name your files:
    [Drawing#]_[Title]_Rev[#]
  4. Upload to SharePoint:
    • DWG → Working_Drawings folder
    • PDF → Same folder, add "_REVIEW"
  5. Add metadata when prompted:
    • Drawing Number
    • Revision
    • Scale
    • Select Reviewer from dropdown
  6. Auto-notification sent to reviewer!
💡 PRO TIP: Create a PDF preset in AutoCAD for consistent exports. Save as "SharePoint Review" for one-click plotting.
✍️ FOR REVIEWERS/APPROVERS
  1. Click link in email notification
  2. PDF opens in browser (or download for detailed review)
  3. Review using PDF tools:
    • Add comments/clouds
    • Measure dimensions (if needed)
    • Check against standards
  4. Complete QA checklist (appears automatically):
    • Title block information correct
    • Scale and dimensions verified
    • Drawing standards compliance
    • Cross-references checked
    • Revision clouds present (if applicable)
  5. Click "Approve" or "Needs Revision"
  6. System records your review automatically
⚠️ REMEMBER: You're reviewing the PDF, not the CAD file. If you need to check something in CAD, download the DWG separately.
⚡ Quick Reference Cards
🔍 Finding Drawings
By Drawing Number:
Use search box, type drawing number

By Status:
Filter view to "Pending Review" or "Approved"

By Date:
Sort by "Modified" column
📏 File Size Limits
Maximum file size: 250MB
If file is too large:
• Purge unused blocks in CAD
• Use ZIP for multiple files
• Contact IT for large models

Typical sizes:
DWG: 5-50MB | PDF: 1-10MB
🔄 Revision Process
After reviewer comments:
1. Download marked-up PDF
2. Update CAD drawing
3. Increment revision (Rev2 → Rev3)
4. Upload new DWG + PDF
5. Previous files auto-archived

Old versions always accessible in Version History
✅ QA Compliance
Automatic QA tracking:
• Who reviewed (login name)
• When reviewed (timestamp)
• What was checked (QA fields)
• Comments/markups (in PDF)

Export for audits:
Library → Export to Excel → Full QA report with all metadata
🚫 Common Mistakes
DON'T:
❌ Upload only DWG (need PDF too)
❌ Edit files without check-out
❌ Use spaces in filenames
❌ Forget to add metadata

DO:
✅ Always upload both files
✅ Use standard naming convention
🛠️ Troubleshooting
PDF won't display:
Download and open locally

Can't upload:
Check file size and permissions

XREFs broken:
Use eTransmit or bind XREFs before uploading

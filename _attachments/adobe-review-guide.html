📋 Step-by-Step Process for Shared Review
🎨 FOR DOCUMENT ORIGINATORS
  1. Prepare your PDF
    • Export from CAD with layers preserved
    • Enable commenting rights
    • Run Accessibility Check if needed
  2. Start Shared Review
    • Click "Share" → "Send for Comments"
    • Choose "Shared Network Folder"
    • Select SharePoint location or network drive
  3. Configure review settings
    • Set deadline (optional)
    • Add reviewer emails
    • Include message/instructions
  4. Send invitations
  5. Monitor in Tracker
    • View → Tracker
    • See who's reviewed
    • Send reminders if needed
  6. Manage comments
    • Reply to questions
    • Mark status (accepted/rejected)
    • Export summary to Excel
💡 PRO TIP: Create an Action Wizard sequence to automatically prepare CAD exports for review (flatten certain layers, add watermarks, enable commenting).
✍️ FOR REVIEWERS
  1. Open review link from email invitation
  2. PDF opens in Acrobat with review panel active
  3. Use commenting tools:
    • Sticky notes for general comments
    • Text edits for specific changes
    • Drawing tools for clouds/arrows
    • Measure tool for dimensions
    • Stamps for approval status
  4. Categorize comments
    • Right-click → Properties
    • Set status/checkmarks
    • Add tags for sorting
  5. See others' comments in real-time (shared review)
  6. Click "Publish Comments" when done
⚠️ IMPORTANT: Always click "Publish Comments" before closing. Draft comments aren't visible to others until published!

✅ How Adobe Satisfies QA Requirements
📝 Automatic Audit Trail
Every comment includes: reviewer name, timestamp, status, replies. Meets QUAL3130 traceability requirements.
📊 Comments Summary Report
Export all comments to Word/Excel with page numbers, categories, and responses. This becomes your QA form.

Built-in digital signature capability with certificates. Complies with QUAL3130 authentication requirements.

Reviewed PDFs with embedded comments can be stored in your existing folder structure (Admin/17-Deliverables).

📋 Step-by-Step Process
🎨 ORIGINATOR WORKFLOW
  1. Export from CAD to PDF
    • Include all layers
    • Vector format (not raster)
    • Enable "Searchable Text"
    • Maintain scale (1:1)
  2. Open in Bluebeam Revu
  3. Upload to Studio Project
    • Right-click → Upload to Studio
    • Select project folder
  4. Create Review Session
    • Name: "[Drawing#]_Review_[Date]"
    • Set permissions (view/markup/admin)
    • Add reviewers by email
  5. Monitor progress in real-time
  6. Download marked PDF when complete
  7. Update CAD based on markups
💡 TIP: Use Bluebeam's Batch Link to update multiple sheets at once when references change.
✍️ REVIEWER WORKFLOW
  1. Receive email invitation with session link
  2. Join Studio Session
    • Opens in Bluebeam automatically
    • Your name/initials appear on markups
  3. Use Professional Tools:
    • Measure dimensions & areas
    • Add revision clouds
    • Insert callout boxes
    • Place dimension strings
    • Apply status stamps
    • Highlight issues
  4. Toggle layers to isolate systems
  5. Compare to previous revision (if needed)
  6. Apply QA stamp when complete
  7. Save & Sync - others see immediately
⚠️ IMPORTANT: All markups are tracked by user and timestamp. This serves as your QA documentation.

🔗 Integration with Your Systems
📁 SharePoint Integration
Studio Projects can sync with SharePoint document libraries. Approved PDFs automatically push to SharePoint for record retention while review happens in Bluebeam.
📧 Email Notifications
Automatic notifications when drawings are ready for review, when comments are added, or when approval is complete. No manual follow-up needed.
📊 QA/QC Documentation
Every markup is tracked: who, what, when. Export complete markup summaries as CSV for QA records. Meets all audit requirements automatically.
🔐 Permission Control
Set who can view, markup, or administer. Some users can only view, others can markup, administrators can delete/modify anyone's markups.
📱 Mobile Access
Bluebeam Vu (free viewer) on iPad/tablets for field review. Full Revu on Windows tablets for complete functionality on-site.
🔄 Batch Processing
Apply stamps, add headers/footers, or run QA checks on multiple drawings at once. Huge time saver for large drawing sets.

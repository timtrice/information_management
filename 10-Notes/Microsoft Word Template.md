Authors shall download the selected template to their working directory. From there, the following edits shall be made to the document.

1. Rename the file to the respective document number.
2. Edit the header of the document
	a.     With file open, select the "Insert" ribbon
	b.     Click the down arrow under "Header" in the "Header & Footer" pane.
	c.     Select "Edit Header".
		i.    There are two headers to update; both largely repetitive.
			1. Update Document title
			2. Update Document Number
			3. Update Security Classification per MDR or Site
			4. Update Export Code per MDR or Site
		ii.    Update the revision block in the footer on the cover page. The revision block shall be contained to no more than three rows with the most recent revision listed first.
			5. Revision
			6. Issue Status
			7. Originator
			8. Reviewer
			9. Approver
			10. (Revision) Date
		iii.    Click "Close Header and Footer"
3. On cover page, update Document Title
4. From pg. 3 forward document contents can be deleted and replaced with the contents of the true document.

When the document is complete, the discipline lead may place the document in the Project's shared i-drive within the respective subject folder. Originator shall then email a link to the folder to [documentcontrol@hanson-inc.com](mailto:documentcontrol@hanson-inc.com) for review and release.

The following discipline codes shall be used for all Market projects and documents:

| Code | Description                 |
| :--: | --------------------------- |
| PMG  | Project Management          |
| CIV  | Civil                       |
| ELE  | Electrical                  |
| CST  | Cost and Planning           |
| HLT  | Health                      |
| SAF  | Safety                      |
| ENV  | Environment                 |
| SEC  | Security                    |
| INS  | Instrumentation             |
| INF  | Information Management      |
| MEC  | Mechanical                  |
| PRC  | Process                     |
| CPR  | Contracting and Procurement |
| PIP  | Piping                      |
| STR  | Structural                  |
| RAL  | Rail                        |

Discipline codes are 3-character alphabetic strings and shall be selected from this approved list only. New discipline codes may be added through formal procedure revision process.

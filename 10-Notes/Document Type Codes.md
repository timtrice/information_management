The following document type codes shall be used for all Market projects and documents:

| Code | Description             | Typical Content                                                                                            |
| :--: | ----------------------- | ---------------------------------------------------------------------------------------------------------- |
| CAL  | Calculations            | Equipment calculations, structural calculations, analysis calculations                                     |
| DWG  | Drawings                | Arrangement diagrams, block diagrams, layouts, wiring diagrams, general diagrams                           |
| RPT  | Reports                 | Analysis reports, equipment reports, inspection reports, performance reports, review reports, test reports |
| SPC  | Specifications          | Technical specifications and requirements                                                                  |
| DAT  | Data                    | Data sheets, general data documents                                                                        |
| LST  | Lists                   | Registers, lists                                                                                           |
| PRO  | Procedures/Manuals      | Manuals, philosophies, procedures, operational documents                                                   |
| PLN  | Plans/Studies           | Plans, studies, strategic documents                                                                        |
| TRM  | Transmittals/Requests   | Transmittals, requests, formal communications                                                              |
| COR  | Correspondence          | Project correspondence, letters, communications                                                            |
| CRT  | Certificates            | Certificates, certifications, formal attestations                                                          |
| TMP  | Templates               | Document templates, forms, standardized formats                                                            |
| QCR  | Quality Control Reports | Audit trail documentation, review session exports                                                          |
| MRQ  | Material Requisition    | Formal procurement package                                                                                 |
| GEN  | General/Miscellaneous   | General documents, narratives, miscellaneous items                                                         |

Document type codes are 3-character alphabetic strings and shall be selected from this approved list only. New document type codes may be added through formal procedure revision process.

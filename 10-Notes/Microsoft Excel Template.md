Authors shall download the selected template to their working directory. From there, the following edits shall be made to the document.

1. Rename the file to the respective document number.
2. On the cover page, update
	a.     Document Title in K1 and A19
	b.     Document Number in K2
	c.     Security Class in K3
	d.     Export Code in R3
	e.     Revision block. The revision block shall be contained to no more than three rows with the most recent revision listed first.
	  i.    Revision
	  ii.    Issue Status
	  iii.    Originator
	  iv.    Reviewer
	  v.    Approver
	  vi.    (Revision) Date
3. On each worksheet (with the exception of the cover page),
	a.     Select "Page Layout" in the ribbon panel.
	b.     Click the arrow icon in the lower-right of the Page Setup pane.
	c.     Select the "Header/Footer" tab
	d.     Make sure the following selections are enabled:
		i.    Different first page
		ii.    Scale with document
		iii.    Align with page margins
	e.     Select "Custom Header"
	f.      With the Header tab selected, and in the "Right section" window, add
		i.    Document Number
		ii.    Document Revision
		iii.    Revision Date

When the document is complete, the discipline lead may place the document in the Project's shared i-drive within the respective subject folder. Originator shall then email a link to the folder to [documentcontrol@hanson-inc.com](mailto:documentcontrol@hanson-inc.com) for review and release.

## Class Definitions

**Class I - Small-Scale Projects**

Small-scale projects with limited scope and complexity requiring minimal external stakeholder coordination. Market staff handles all document control tasks independently without Information Management/Document Control (IM/DC) personnel involvement.

**Class II - Standard External Review Projects**

Standard projects involving external review sessions with Client requiring moderate complexity and IM/DC support. These projects involve coordination between Company and Client document management systems with multiple stakeholder involvement.

**Class III - Main Information Contractor Projects**

Complex projects where Market acts as Main Information Contractor (MIC) with comprehensive responsibility for all document control and information management aspects. Client has minimal IM/DC processes, requiring Market to establish and maintain complete document management systems.

## Classification Authority

The Project Manager (PM) and Market Principal (MP) shall determine project classification during project initiation.

## Requirements by Class

**Class I Requirements**

- No SharePoint usage
- No IM/DC personnel involvement
- Store all project documents on Company network drive
- Follow O → TM → POR review cycle via Bluebeam
- Maintain detailed tracking and documentation of all review activities
- Apply Security Classification system (default "Restricted")

**Class I Best Practices**

- Implement Issue Status Codes for enhanced tracking
- Use formal revision numbering system
- Maintain audit trail documentation

**Class II Requirements (extends Class I)**

- IM/DC services support required
- Mandatory implementation of Issue Status Codes
- Formal revision tracking and documentation
- Comprehensive audit trail requirements
- External stakeholder coordination protocols
- SharePoint for deliverables management and version control
- Integration with Client EDMS as required
- Dual metadata systems when Client requirements conflict with Company requirements

**Class III Requirements (extends Class I)**

- Complete IM/DC team involvement and oversight
- Complete document management system implementation
- Advanced metadata tracking and reporting
- Complex review workflows with multiple stakeholder coordination
- Comprehensive audit trail and compliance documentation
- Full SharePoint implementation with advanced workflows
- Custom reporting and dashboard capabilities
- Integration with multiple stakeholder systems as required

## Universal Requirements

All project classes shall maintain:

- Universal review process via Bluebeam
- Company document numbering format compliance
- Security Classification system implementation

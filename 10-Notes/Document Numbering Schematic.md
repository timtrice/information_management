## Format Structure

All Market documents shall follow established numbering formats based on project classification. The numbering schematic provides systematic identification and organization of documents throughout their lifecycle.

### Class I Projects

Class I projects shall use the following format:

**AAA-BBB-CCC-DDDD**

Where:

- AAA = Project identifier (alphanumeric string)
- BBB = Discipline code (3-character alphabetic string)
- CCC = Document type code (3-character alphabetic string)
- DDDD = Sequential number (4-digit numeric string, discipline-specific)

### Class II and Class III Projects

Class II and Class III projects shall use the following format:

**AAA-OO-BBB-CCC-DDDD**

Where:

- AAA = Project identifier (alphanumeric string)
- OO = Originator code (2-character alphabetic string)
- BBB = Discipline code (3-character alphabetic string)
- CCC = Document type code (3-character alphabetic string)
- DDDD = Sequential number (4-digit numeric string, discipline-specific) or date format (YYMMDD)

### Code Separation Requirements

Originator codes, discipline codes, and document type codes shall never share identical codes to prevent ambiguity. The character length restrictions ensure clear distinction between code categories.

### Sequential Numbering Rules

- Sequential numbers shall be discipline-specific within each document type
- Numbers shall begin at 0001 for each discipline/document type combination
- VOID document numbers shall never be reused under any circumstances
- CAN document numbers shall not be reused for operational simplicity
- Sequential gaps from retired numbers remain permanent in the numbering system

## Market Documents

Market-specific documents shall use the format:

**IND-BBB-CCC-DDDD**

Where IND identifies the Market business unit and follows the same coding structure as project documents for discipline, document type, and sequential numbering.

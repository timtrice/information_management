title: Return Status Codes
created: 2026-04-30T11:20:30Z
modified: 2026-04-30T11:22:46Z
---

Unless otherwise noted, the following shall be considered industry-standard return status codes:

- Code 1: Approved. Documents do not require resubmittal.
- Code 2: Approved with comments. Documents are to incorporate comments and resubmitted for approval. Work may proceed.
- Code 3: Rejected. Documents are to incorporate comments and resubmitted. Work may not proceed.
- Code 4: Information Only. Document review/approval is not required.
- Code 5: VOID. Document has been voided.
